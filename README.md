# ⚔️ Infinite Text Dungeon Crawler (Бесконечный текстовый рогалик)

Атмосферная текстовая RPG с процедурной генерацией и поддержкой LLM в качестве Мастера Подземелий (Dungeon Master).

### 🕹️ Особенности:
- **3 визуальных темы:**
  - 🖥️ **DOS Amber CRT:** тёплый янтарный монохром со скайлайнами, виньеткой и мерцанием.
  - 🟢 **Green Phosphor:** классический терминальный хакерский зелёный.
  - 📜 **Ancient Scroll:** готический стиль старинного манускрипта / фэнтези-свитка.
- **Встроенный процедурный генератор звука (Web Audio API):**
  - Олдскульный стук клавиш печатной машинки.
  - Низкий эмбиентный гул подземелья (dungeon drone).
  - Звуки звона клинков, получения урона, распития зелий, бросков костей d20 и левелапа.
- **Два режима Dungeon Master:**
  - **Автономный процедурный движок:** работает прямо из коробки без интернета и без API ключей!
  - **Нейросетевой режим (AI DM):** поддержка **Gemini API** или **Ollama / OpenRouter** (настраивается прямо в игре по кнопке `⚙ LLM / AI`).
- **Глубокая RPG-механика:**
  - Здоровье (HP), Мана/Стамина, Уровни, Опыт, Золото, Этажи катакомб.
  - Экипировка, артефакты, заплечный инвентарь с лечебными зельями.
  - Свободная командная строка: можно писать любое действие (например: *"осмотреть потолок"*, *"разбить алтарь"*, *"попробовать договориться с гоблином"*).

---

### 🚀 Как запустить:
1. Просто откройте файл `index.html` в любом браузере (Chrome, Edge, Firefox, Safari).
2. Или дважды кликните по `start.bat`.
